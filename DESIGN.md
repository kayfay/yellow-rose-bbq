## 3. Affected Files

| File | Responsibility |
|---|---|
| `scripts/plate_bom_line_item_report.py` | Emits `clover_api/analytics/plate_cost_explorer.json` (plain-English, zero banned jargon) in addition to the `0600` standalone CSV/HTML/PDF reports. |
| `scripts/generate_boss_master_exports.py` | Adds the **Page 1 Category-by-Category Base vs. Full To-Go Food Cost Rollup & Cost-Reduction Highlights** table to `YRBBQ_Complete_COGS_and_Inventory_Master_2026-11-15.html` & `.pdf`, then appends Appendices A, B & C. |
| `clover_api/analytics/build_payloads.py` | Bundles `plate_cost_explorer.json` into `payloads.js`. |
| `index.html` | Adds `#btn-subtab-plate-costs` (`🧾 Plate & Recipe Costs`) next to `#btn-subtab-reports` and the `#subtab-view-plate-costs` container (with `.subtab-stat-strip`, Page 1 Category Rollup `.rollup-section`, search/filter toolbar, and expandable 137-item & 34-recipe tables). |
| `modules/forecaster/analytics_subtabs.js` | Wires `#btn-subtab-plate-costs` switching, live search, category/margin filtering, column sorting, and in-place row expansion for all 137 menu items and 34 recipes. |
| `style.css` | Styles `.plate-explorer-toolbar`, `.plate-explorer-table`, expandable BOM detail rows, Okabe-Ito status badges, and mobile responsive card/table layout (`>= 48px` tap targets). |
| `tests/e2e/plate_cost_explorer.spec.js` | Playwright E2E test verifying `#btn-subtab-plate-costs` navigation, Page 1 Category Rollup table, search/filter, expandable line-by-line BOM drill-down, mobile ergonomics, and zero console errors. |
